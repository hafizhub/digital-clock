# ⏰ Digital Clock

This is a modern and fully responsive **Digital Clock App** designed to display the current time in a clean and intuitive UI. The app focuses on simplicity, accuracy, and user-friendly design.

This project demonstrates frontend development skills and working with real-time JavaScript functionality.

---

## 🌍 Features

- Displays current hours, minutes, and seconds  
- Updates time in real-time  
- Fully responsive layout (Desktop, Tablet & Mobile)  
- Clean and minimalistic user interface  
- Optionally, can include AM/PM format  

---

## 📲 How It Works

The app uses JavaScript’s `Date` object to fetch the current time and updates the display every second.  
Users can view the time in a dynamic, real-time interface.

Benefits:
- Accurate and real-time time display  
- Simple and easy to use  
- No backend required  
- Ideal for learning JavaScript and DOM manipulation
